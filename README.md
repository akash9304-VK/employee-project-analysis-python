# Employee Project Analysis using Python

## Overview
This project analyzes employee project performance data using Python, Pandas, and NumPy.

The project focuses on:
- Data cleaning
- Missing value handling
- DataFrame merging
- Employee performance analysis
- Bonus calculations
- Business rule implementation

---

## Technologies Used
- `Python`
- `Pandas`
- `NumPy`
- `Jupyter Notebook`

---

## Project Tasks

### 1. DataFrame Creation
Created multiple datasets for employees, projects, and seniority levels.

### 2. Missing Value Handling
Handled missing project cost values using running averages.

### 3. Data Cleaning
Split employee names into first and last names.

### 4. DataFrame Merging
Merged multiple datasets into a unified analysis dataframe.

### 5. Bonus Calculation
Calculated 5% bonuses for employees with completed projects.

### 6. Designation Updates
Applied promotion and demotion logic based on project outcomes.

### 7. Employee Analysis
Filtered employee details based on city conditions.

### 8. Project Cost Aggregation
Calculated total project costs handled by employees.

---

# Key Insights

- Employees with completed projects received performance-based bonuses.
- Failed projects affected employee designation levels.
- Senior employees handled higher overall project costs.
- Data aggregation helped evaluate employee contribution across projects.
- Missing project costs were successfully handled using running averages.
